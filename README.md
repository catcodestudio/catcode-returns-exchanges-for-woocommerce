# CatCode Returns & Exchanges Manager for WooCommerce

Return, exchange and warranty claim requests for WooCommerce: My Account and guest form, return or claim period, statuses, waybills, e-mails.

This repository mirrors the free version published on wordpress.org, version 1.1.1.

## Requirements

- WordPress 6.2+ (tested up to 7.1)
- WooCommerce 7.0+ (tested up to 11.3)
- PHP 7.4+

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for the plugin name), or download this repository and upload it to `wp-content/plugins/catcode-returns-exchanges-for-woocommerce/`.
